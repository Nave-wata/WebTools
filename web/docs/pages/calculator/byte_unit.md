# バイト単位変換ツール仕様書

## 概要

「バイト単位変換」ツールは、B（バイト）、KB（キロバイト）、MB（メガバイト）、GB（ギガバイト）、TB（テラバイト）の間でデータサイズを相互に変換するウェブツールです。

## 基本情報

- **ページタイトル**: バイト単位変換
- **URL**: `/calculator/byte_unit`
- **説明**: 入力された値を異なるバイト単位（B、KB、MB、GB、TB）に相互変換するツールです。これらの変換は入力された値を元に、リアルタイムで他の単位の表現に変換することが可能です。

## 機能一覧

1. **バイト単位変換**
    - B（バイト）入力: 入力されたバイト数をKB、MB、GB、TBに変換
    - KB（キロバイト）入力: 入力されたキロバイト数をB、MB、GB、TBに変換
    - MB（メガバイト）入力: 入力されたメガバイト数をB、KB、GB、TBに変換
    - GB（ギガバイト）入力: 入力されたギガバイト数をB、KB、MB、TBに変換
    - TB（テラバイト）入力: 入力されたテラバイト数をB、KB、MB、GBに変換

2. **リアルタイム変換**
    - いずれかの入力欄に値を入力すると、自動的に他の単位に変換

3. **エラー処理**
    - 無効な数値形式が入力された場合にエラーメッセージを表示

## データ処理

- 入力イベントは `oninput` でリアルタイムに処理
- 変換関数:
    - `bytes_to_unit()`: バイト数から指定された単位に変換
    - `unit_to_bytes()`: 指定された単位からバイト数に変換

### 変換処理フロー

1. B（バイト）入力時:
    - B → KB、MB、GB、TBに直接変換

2. 他の単位（KB, MB, GB, TB）入力時:
    - まず入力された単位 → Bに変換
    - 次にB → 他の単位に変換

### 変換式

- 1KB = 1024B
- 1MB = 1024KB = 1,048,576B
- 1GB = 1024MB = 1,073,741,824B
- 1TB = 1024GB = 1,099,511,627,776B

## エラー処理

- 無効な数値（数字以外の文字）が入力された場合のエラー
- 変換処理中に発生するその他のエラー

## 特記事項

- すべての変換はクライアントサイドで実行され、サーバーに送信されない
- 空の入力を行うと、他の入力欄もクリアされる
- 最後に編集されたフィールドを追跡し、変換の方向を管理
- 変換結果は最大10桁の小数部を持つが、末尾の0は除去される
