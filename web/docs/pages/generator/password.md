# パスワード生成ツール仕様書

## 概要

「ランダムパスワード生成」ツールは、ユーザーが指定した条件に基づいてランダムなパスワードを生成するウェブツールです。

## 基本情報

- **ページタイトル**: ランダムパスワード生成
- **URL**: `/generator/password`
- **説明**: 任意の条件でパスワードを生成可能なツールです。使用する英数字や記号など、様々な条件を選択することができます。また、一部の文字や記号を除くといった細かい調整に対応しております。

## 機能一覧

1. **文字種の選択と編集**
    - 英字（大文字）: デフォルトで有効
    - 英字（小文字）: デフォルトで有効
    - 数字: デフォルトで有効
    - 記号: デフォルトで無効
    - 各文字種のカスタマイズ（特定の文字を除外する機能）

2. **パスワード長の設定**
    - プリセット: 8文字、12文字（デフォルト）、16文字
    - カスタム設定: 1〜256文字の範囲で自由に設定可能

3. **生成数の設定**
    - プリセット: 10個、25個（デフォルト）、50個
    - カスタム設定: 1〜200個の範囲で自由に設定可能

4. **パスワード生成機能**
    - 「生成」ボタンをクリックすることで、設定した条件に基づくパスワードを生成

5. **コピー機能**
    - 個別パスワードのコピー（各パスワードの横にあるコピーアイコンをクリック）
    - すべてのパスワードを一括コピー（「すべてコピー」ボタン）
    - ランダムに1つのパスワードをコピー（「ランダムにコピー」ボタン）

## UI構成

### 左側セクション（設定パネル）

1. **「使用する文字」フィールドセット**
    - 4種類の文字種（大文字、小文字、数字、記号）を選択するチェックボックス
    - 各文字種のカスタマイズ用テキストボックス

2. **「パスワードの長さ」フィールドセット**
    - ラジオボタングループ（8文字、12文字、16文字、カスタム）
    - カスタム長さ用の数値入力フィールド

3. **「生成する個数」フィールドセット**
    - ラジオボタングループ（10個、25個、50個、カスタム）
    - カスタム個数用の数値入力フィールド

4. **アクションボタン**
    - 「生成」ボタン: パスワードを生成
    - 「すべてコピー」ボタン: 生成されたすべてのパスワードをコピー
    - 「ランダムにコピー」ボタン: ランダムにパスワードを1つ選んでコピー

### 右側セクション（結果パネル）

1. **「パスワード」フィールドセット**
    - 生成されたパスワードのグリッド表示
    - 各パスワードの横にコピーボタン

### 下部セクション

1. **使い方説明**
    - 基本的な使い方
    - パスワードのコピー方法
    - カスタマイズのヒント

## エラー処理

- パスワードの長さが1〜256の範囲外の場合にエラーメッセージを表示
- 生成数が1〜200の範囲外の場合にエラーメッセージを表示
- パスワード生成時にエラーが発生した場合にエラーメッセージを表示
- コピー操作時にパスワードが存在しない場合にエラーメッセージを表示

## 特記事項

- パスワード生成には、ランダム性の高い乱数生成アルゴリズムを使用
- クリップボード操作のために、Web API（navigator.clipboard）を使用
- コピー成功時には「コピーされました」というトースト通知を表示
