# 文字数カウントツール仕様書

## 概要

「文字数カウント」ツールは、入力されたテキストの文字数、単語数、行数、バイト数をリアルタイムでカウントするウェブツールです。

## 基本情報

- **ページタイトル**: 文字数カウント
- **URL**: `/counter/text_length`
- **説明**: 入力された文字の文字数などをカウントするツールです。文字数だけでなく、空文字区切りでの単語数カウントや行数、Byte数のカウントにも対応しています。また、これらのカウントは入力に伴いリアルタイムで行われるため、非常にスムーズなカウントが可能です。

## 機能一覧

1. **テキスト入力**
    - 複数行のテキスト入力が可能なテキストエリア

2. **リアルタイムカウント**
    - 文字数カウント: テキスト内の文字数をカウント
    - 単語数カウント: スペースや改行で区切られた単語の数をカウント
    - 行数カウント: 改行で区切られた行の数をカウント
    - バイト数カウント: UTF-8エンコーディングでのバイト数をカウント

## UI構成

### テキスト入力セクション

1. **「テキストを入力」見出し**

2. **テキストエリア**
    - 複数行のテキスト入力が可能
    - プレースホルダー: 「ここにテキストを入力してください...」
    - 高さ: 10行

### カウント結果セクション

1. **「カウント結果」見出し**

2. **カウント表示グリッド**
    - レスポンシブグリッド (スマートフォンでは2列、デスクトップでは4列)
    - 4つのカウントボックス
        - 文字数表示ボックス
        - 単語数表示ボックス
        - 行数表示ボックス
        - バイト数表示ボックス

### 使い方説明セクション

1. **基本的な使い方**
    - 入力方法と結果表示の説明

2. **カウント項目の説明**
    - 各カウント項目（文字数、単語数、行数、バイト数）の詳細説明

3. **活用例**
    - ツールの具体的な活用シーン

## データ処理

- カウント処理は `crate::libs::counter` モジュールに実装
    - `count_chars()`: 文字数をカウント
    - `count_words()`: 単語数をカウント
    - `count_lines()`: 行数をカウント
    - `count_bytes()`: バイト数をカウント

### カウント方法

1. **文字数**
    - すべての文字（スペースや改行を含む）をカウント

2. **単語数**
    - スペースや改行で区切られた単語をカウント
    - 連続したスペースは1つの区切りとして扱う

3. **行数**
    - 改行（\n）で区切られた行の数をカウント
    - 最後の行に改行がなくても1行としてカウント

4. **バイト数**
    - UTF-8エンコーディングでのバイト数をカウント

## 特記事項

- カウントはリアルタイムで行われ、入力のたびに更新される
- モバイルデバイスにも対応したレスポンシブデザイン
- テキストはサーバーに送信されず、すべてクライアントサイドで処理される
- SNSの文字数制限チェックや、レポート・論文の文字数確認、プログラムのソースコード行数確認など、さまざまな用途に活用可能
