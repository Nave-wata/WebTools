# Base エンコード/デコード仕様書

## 概要

「Base エンコード/デコード」ツールは、Base16 (Hex)、Base32、Base64 形式でテキストをエンコードしたり、エンコードされたデータをデコードしたりするウェブツールです。

## 基本情報

- **ページタイトル**: Base エンコード/デコード
- **URL**: `/converter/base_endecode`
- **説明**: Base16, Base32, Base64 のエンコードとデコードを行うツールです。テキストを各種Base形式でエンコードしたり、エンコードされたデータをデコードしたりすることができます。

## 機能一覧

1. **Base16 (Hex) エンコード/デコード**
    - 通常テキストを Base16 (16進数) 形式に変換
    - Base16 形式のデータを通常テキストに変換

2. **Base32 エンコード/デコード**
    - 通常テキストを Base32 形式に変換
    - Base32 形式のデータを通常テキストに変換

3. **Base64 エンコード/デコード**
    - 通常テキストを Base64 形式に変換
    - Base64 形式のデータを通常テキストに変換

4. **リアルタイム変換**
    - いずれかの入力欄に値を入力すると、自動的に他の形式に変換

5. **エラー処理**
    - 無効なエンコード形式が入力された場合にエラーメッセージを表示

## UI構成

### Base エンコード/デコードセクション

1. **「Base エンコード/デコード」見出し**

2. **説明テキスト**
    - 「いずれかの入力欄に値を入力すると、自動的に他の形式に変換されます。」

3. **入力フィールドグリッド**
    - レスポンシブデザイン（スマートフォンでは1列、大きな画面では2列）
    - 4つの入力フィールド
        - 通常テキスト入力フィールド（ラベル: 「通常テキスト」）
        - Base16入力フィールド（ラベル: 「Base16 (Hex)」）
        - Base32入力フィールド（ラベル: 「Base32」）
        - Base64入力フィールド（ラベル: 「Base64」）

4. **エラー表示エリア**
    - エラーが発生した場合に赤色の背景でエラーメッセージを表示

### 使い方説明セクション

1. **基本的な使い方**
    - 「通常テキスト」欄に文字を入力すると、他の3つの欄に自動的にエンコードされた結果が表示される
    - Base16、Base32、Base64のいずれかの欄に文字を入力すると、「通常テキスト」欄と他の2つの欄に自動的に変換された結果が表示される

2. **各Base形式について**
    - **Base16 (Hex)**: 16進数表記。0-9とa-fの文字を使用
    - **Base32**: 32文字のアルファベット（A-Z、2-7）を使用。パディングに=を使用
    - **Base64**: 64文字（A-Z、a-z、0-9、+、/）を使用。パディングに=を使用

## データ処理

- 入力イベントは `oninput` でリアルタイムに処理
- 変換処理は `crate::libs::base` モジュールに実装
    - `base16_encode()`: 通常テキストを Base16 形式に変換
    - `base16_decode()`: Base16 形式を通常テキストに変換
    - `base32_encode()`: 通常テキストを Base32 形式に変換
    - `base32_decode()`: Base32 形式を通常テキストに変換
    - `base64_encode()`: 通常テキストを Base64 形式に変換
    - `base64_decode()`: Base64 形式を通常テキストに変換

### 変換処理フロー

1. 通常テキスト入力時:
    - 入力テキストを Base16、Base32、Base64 の各形式にエンコード
    - 結果を対応する入力欄に表示

2. Base16入力時:
    - Base16 形式をデコードして通常テキストに変換
    - 通常テキストを Base32、Base64 形式にエンコード
    - 結果を対応する入力欄に表示

3. Base32入力時:
    - Base32 形式をデコードして通常テキストに変換
    - 通常テキストを Base16、Base64 形式にエンコード
    - 結果を対応する入力欄に表示

4. Base64入力時:
    - Base64 形式をデコードして通常テキストに変換
    - 通常テキストを Base16、Base32 形式にエンコード
    - 結果を対応する入力欄に表示

## エンコード/デコード実装

- WASM環境での互換性のため、外部クレートを使用せず純粋なRustコードで実装
- Base16: 標準的な16進数エンコード/デコード
- Base32: RFC 4648準拠のBase32エンコード/デコード（A-Z、2-7、パディング=）
- Base64: RFC 4648準拠のBase64エンコード/デコード（A-Z、a-z、0-9、+、/、パディング=）

## エラー処理

- Base16デコード時の無効な16進数文字エラー
- Base16デコード時の無効な長さエラー（奇数文字）
- Base32デコード時の無効な文字エラー
- Base64デコード時の無効な文字エラー
- デコード結果が無効なUTF-8文字列の場合のエラー

## 特記事項

- すべての変換はクライアントサイドで実行され、サーバーに送信されない
- 空の入力を行うと、他の入力欄もクリアされる
- 最後に編集されたフィールドを追跡し、変換の方向を管理
- Base32とBase64のパディング文字（=）は自動的に処理される
