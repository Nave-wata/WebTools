# URL エンコード/デコード仕様書

## 概要

「URL エンコード/デコード」ツールは、URL で使用できない文字をエンコードしたり、エンコードされた URL をデコードしたりするウェブツールです。

## 基本情報

- **ページタイトル**: URL エンコード/デコード
- **URL**: `/converter/url_endecode`
- **説明**: URL のエンコードとデコードを行うツールです。URL で使用できない文字をエンコードしたり、エンコードされた URL をデコードしたりすることができます。

## 機能一覧

1. **URL エンコード**
    - 通常テキストを URL エンコード形式に変換
    - http:// や https:// などのスキーマ部分はエンコードせずにそのまま保持

2. **URL デコード**
    - URL エンコードされたテキストを通常テキストに変換
    - %で始まるエンコード文字列を元の文字に戻す
    - +記号をスペースに変換

3. **リアルタイム変換**
    - いずれかの入力欄に値を入力すると、自動的に変換

4. **エラー処理**
    - 無効なエンコード形式が入力された場合にエラーメッセージを表示

## UI構成

### URL エンコード/デコードセクション

1. **「URL エンコード/デコード」見出し**

2. **説明テキスト**
    - 「いずれかの入力欄に値を入力すると、自動的に変換されます。http://やhttps://のようなスキーマ部分はエンコードされません。」

3. **入力フィールドグリッド**
    - レスポンシブデザイン（スマートフォンでは1列、大きな画面では2列）
    - 2つの入力フィールド
        - 通常テキスト入力フィールド（ラベル: 「通常テキスト」）
        - エンコード済みテキスト入力フィールド（ラベル: 「エンコード済みテキスト」）

4. **エラー表示エリア**
    - エラーが発生した場合に赤色の背景でエラーメッセージを表示

### 使い方説明セクション

1. **基本的な使い方**
    - 左側の「通常テキスト」欄に文字を入力すると、右側の「エンコード済みテキスト」欄に自動的にエンコードされた結果が表示される
    - 右側の「エンコード済みテキスト」欄に文字を入力すると、左側の「通常テキスト」欄に自動的にデコードされた結果が表示される
    - http://やhttps://のようなスキーマ部分はエンコードされずにそのまま表示される

2. **URL エンコードとは**
    - URL エンコードは、URL で使用できない文字（日本語や特殊文字など）を URL で使用できる形式に変換すること
    - 例えば、スペースは「%20」に、日本語は「%E3%81%82」のような形式に変換される

## データ処理

- 入力イベントは `oninput` でリアルタイムに処理
- 変換処理は `crate::libs::url` モジュールに実装
    - `url_encode()`: 通常テキストを URL エンコード形式に変換
    - `url_decode()`: URL エンコード形式を通常テキストに変換
    - `detect_url_schema()`: URL スキーマ部分を検出

### 変換処理フロー

1. 通常テキスト入力時:
    - URL スキーマ部分を検出
    - スキーマ部分はそのままで、残りの部分をエンコード
    - 結果をエンコード済みテキスト欄に表示

2. エンコード済みテキスト入力時:
    - URL スキーマ部分を検出
    - スキーマ部分はそのままで、残りの部分をデコード
    - 結果を通常テキスト欄に表示

## エンコード/デコード実装

- URL エンコード/デコードの実装には `url` クレートを使用
- URL スキーマ部分（http://, https://）は検出して保持
- エンコード時は `url::form_urlencoded::byte_serialize` を使用
- デコード時は `url::form_urlencoded::parse` を使用
- エラー処理は独自に実装（不完全なパーセントエンコードなどの検出）

## エラー処理

- 不完全なパーセントエンコード（%の後に2文字の16進数がない）の場合のエラー
- 無効なパーセントエンコード（%の後の2文字が16進数でない）の場合のエラー
- デコード処理中に発生するその他のエラー

## 特記事項

- すべての変換はクライアントサイドで実行され、サーバーに送信されない
- 空の入力を行うと、他の入力欄もクリアされる
- 最後に編集されたフィールドを追跡し、変換の方向を管理
