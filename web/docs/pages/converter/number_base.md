# 進数変換ツール仕様書

## 概要

「進数変換」ツールは、2進数、10進数、16進数の間で相互に数値を変換するウェブツールです。

## 基本情報

- **ページタイトル**: 進数変換
- **URL**: `/converter/number_base`
- **説明**: 入力された数値を相互に進数変換するツールです。2進数、10進数、16進数の相互変換に対応しています。これらの変換は入力された数値を元に、リアルタイムで残り2種類の表現に変換することが可能です。

## 機能一覧

1. **進数変換**
    - 2進数入力: 入力された2進数を10進数と16進数に変換
    - 10進数入力: 入力された10進数を2進数と16進数に変換
    - 16進数入力: 入力された16進数を2進数と10進数に変換

2. **リアルタイム変換**
    - いずれかの入力欄に値を入力すると、自動的に他の進数形式に変換

3. **エラー処理**
    - 無効な数値形式が入力された場合にエラーメッセージを表示

## UI構成

### 進数変換セクション

1. **「進数変換」見出し**

2. **説明テキスト**
    - 「いずれかの入力欄に値を入力すると、自動的に他の進数に変換されます。」

3. **入力フィールドグリッド**
    - レスポンシブデザイン（スマートフォンでは1列、大きな画面では3列）
    - 3つの入力フィールド
        - 2進数入力フィールド（ラベル: 「2進数」）
        - 10進数入力フィールド（ラベル: 「10進数」）
        - 16進数入力フィールド（ラベル: 「16進数」）

4. **エラー表示エリア**
    - エラーが発生した場合に赤色の背景でエラーメッセージを表示

### 使い方説明セクション

1. **基本的な使い方**
    - 各入力欄の使用方法と入力可能な文字の説明
    - 2進数: 0と1のみ
    - 10進数: 0から9までの数字
    - 16進数: 0から9までの数字とAからFまでの文字（大文字・小文字どちらも可）

## データ処理

- 入力イベントは `oninput` でリアルタイムに処理
- 変換処理は `crate::libs::number` モジュールに実装
    - `base_to_decimal()`: 指定された基数の数値を10進数に変換
    - `decimal_to_base()`: 10進数を指定された基数の数値に変換

### 変換処理フロー

1. 2進数入力時:
    - 2進数 → 10進数に変換
    - 10進数 → 16進数に変換

2. 10進数入力時:
    - 10進数 → 2進数に変換
    - 10進数 → 16進数に変換

3. 16進数入力時:
    - 16進数 → 10進数に変換
    - 10進数 → 2進数に変換

## エラー処理

- 無効な2進数（0,1以外の文字）が入力された場合のエラー
- 無効な10進数（数字以外の文字）が入力された場合のエラー
- 無効な16進数（0-9, A-F以外の文字）が入力された場合のエラー
- 変換処理中に発生するその他のエラー

## 特記事項

- すべての変換はクライアントサイドで実行され、サーバーに送信されない
- 空の入力を行うと、他の入力欄もクリアされる
- 最後に編集されたフィールドを追跡し、変換の方向を管理
